## 1.1 Продукт

| Поле | Значение |
|------|----------|
| Название | **RelativitySim Pro** |
| Подзаголовок (RU) | Интерактивный симулятор Специальной теории относительности |
| Подзаголовок (EN) | Interactive Special Relativity Simulator |
| Тип | SPA, образовательно-научная интерактивная лаборатория СТО |
| Платформа | Современный desktop Chrome/Firefox/Edge; mobile — usable (панели collapsible), desktop — primary |
| Рендер | HTML5 Canvas 2D × 2 (кабина + карта наблюдателя) |
| Научный уровень | Специальная теория относительности Эйнштейна: \(\gamma\), dilation, contraction, aberration, Doppler; образовательная 2D-визуализация, не полная GR / ray-tracing через метрику |

**Ценность:** дать пользователю «кабину релятивистского корабля» и «пульт ЦЕРН», где можно разогнаться почти до \(c\) и **увидеть** эффекты СТО: стягивание неба вперёд, blueshift/redshift, сжатие длин, расхождение часов (парадокс близнецов), постоянство скорости света для лазеров.

**Аудитория:** студенты физики/астрофизики, преподаватели СТО, энтузиасты космоса, разработчики, изучающие Angular + scientific visualization.

## 1.2 Информационная архитектура экрана

Один главный экран (без роутинга страниц) — **Relativistic Dashboard / Cockpit Control Room**:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Toolbar: RelativitySim Pro | presets β | theme | lang | screenshot | hotkeys │
├─────────────────────────────┬────────────────────────────┬───────────────────┤
│                             │                            │ Telemetry         │
│   Cockpit View (Canvas)     │   Observer Map (Canvas)    │  - Earth clocks   │
│   starfield + planets       │   side view / sector map   │  - Ship clocks    │
│   aberration + Doppler      │   ship length contraction  │  - v/c, γ, mγ     │
│                             │                            │  - β readout      │
├─────────────────────────────┴────────────────────────────┴───────────────────┤
│ Bottom: v/c slider | Play Pause Reset | Laser Fwd/Back | twin-paradox HUD    │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Левая колонка (~40%): **Cockpit View** — вид из кабины вперёд.
- Центральная колонка (~38%): **Observer Map** — вид сбоку со стороны неподвижного наблюдателя.
- Правая колонка (~300–340px): бортовой компьютер / телеметрия.
- Нижняя панель (80–96px): слайдер \(v/c\), плеер времени, кнопки лазеров.
- На ширине `< 1100px`: Observer и телеметрия — вкладки / drawer; Cockpit остаётся сверху.
- Z-index: visuals (0) < panels (10) < bottom bar (15) < drawers/modals (30).

Вкладки на узком экране: `Кабина` | `Карта` | `Телеметрия`.

## 1.4 User Journeys (обязательные сценарии)

### J1 — Первый запуск
1. Пользователь открывает приложение.
2. Тема: **dark**. Locale: **ru**.
3. Начальная скорость: \(\beta = v/c = 0\) из [appendix-a-defaults.md](appendix-a-defaults.md).
4. Симуляция часов: **running** (или paused — зафиксируй: **running** по умолчанию).
5. Cockpit показывает неискажённое звёздное поле; Observer — корабль полной длины \(L_0\).
6. Телеметрия: \(\gamma = 1\), \(m\gamma = m_0\), оба времени тикают синхронно.

### J2 — Разгон до релятивистских скоростей
1. Пользователь двигает слайдер \(v/c\) к \(0.5\), \(0.9\), \(0.99\), \(0.999\).
2. \(\gamma\) растёт (computed signal); часы Земли уходят вперёд относительно корабельных.
3. На Cockpit звёзды стягиваются к центру (вперёд) по аберрации; цвета — blueshift/redshift.
4. На Observer корабль сжимается по оси \(X\) как \(L_0/\gamma\).
5. Планеты на Cockpit визуально сближаются по оси движения.

### J3 — Парадокс близнецов (наглядный)
1. Пользователь ставит \(\beta = 0.99\) (пресет или слайдер).
2. Оставляет симуляцию идущей ~10–20 реальных секунд.
3. Видит: «Часы на Корабле» едва тикают относительно «Часов на Земле» (отношение \(\approx\gamma\approx 7.09\)).
4. HUD показывает отношение \(t_{\mathrm{Earth}}/t_{\mathrm{Ship}}\).

### J4 — Лазерный эксперимент
1. Кнопка «Выстрелить лазером вперёд» / «назад».
2. На Observer (и опционально на Cockpit) появляется луч.
3. Для неподвижных планет / карты сектора скорость луча **строго \(c\)** в обе стороны.
4. Цвет/частота луча зависит от направления (вперёд — выше частота / синее; назад — краснее) согласно Доплеру / упрощённой модели из 04.
5. Луч не «обгоняет свет» и не «ползёт медленнее \(c\)» в системе покоя планет.

### J5 — Пресеты \(\beta\)
1. Кнопки: \(0\), \(0.5c\), \(0.9c\), \(0.99c\), \(0.999c\).
2. Пресет мгновенно выставляет \(\beta\) (и обновляет все derived metrics).

### J6 — Pause / Reset
1. Pause останавливает накопление собственного/земного времени и движение лучей.
2. Reset: \(t_{\mathrm{Earth}}=0\), \(t_{\mathrm{Ship}}=0\), очищает активные лазеры, \(\beta\) сохраняется **или** сбрасывается к 0 — зафиксируй: **Reset времени и лазеров; \(\beta\) сохраняется**. Отдельная кнопка «Сброс скорости» → \(\beta=0\).

### J7 — Язык, тема, screenshot
1. Lang RU↔EN через `t(key)`.
2. Theme dark↔light меняет панели; canvas фон остаётся тёмным.
3. Screenshot сохраняет PNG **активного** canvas (cockpit по умолчанию; если фокус/вкладка Observer — observer).

## 1.5 Горячие клавиши

| Key | Действие |
|-----|----------|
| `Space` | Play / Pause часов |
| `R` | Reset времени и лазеров |
| `0`–`4` | Пресеты \(\beta\): 0 / 0.5 / 0.9 / 0.99 / 0.999 |
| `[` / `]` | Уменьшить / увеличить \(\beta\) шагом `BETA_STEP` |
| `F` | Лазер вперёд |
| `B` | Лазер назад |
| `S` | Screenshot активного canvas |
| `T` | Theme toggle |
| `G` | Language RU↔EN |
| `H` | Hotkeys help overlay |
| `Tab` (в mobile tabs) | переключение вкладок — браузерный default; не ломай focus |
| `Esc` | Закрыть overlay |

Игнорировать hotkeys, если фокус в `<input>` / `<textarea>` (кроме Space — допустимо всегда, если не в text input).

## 1.6 Доступность (a11y)

1. Все кнопки и тумблеры — с `aria-label` (через i18n).
2. Play/Pause: `aria-pressed`.
3. Слайдер \(v/c\): связанный `<label>`, `aria-valuemin/max/now`, видимое числовое значение (\(\beta\) и \(\gamma\)).
4. Canvas: `role="img"` + `aria-label` с кратким описанием текущего режима.
5. Контраст текста панелей ≥ WCAG AA на обеих темах.
6. Фокус-кольцо видимо (`:focus-visible`).

## 1.7 Состояния приложения (продуктовые)

| State id | Описание |
|----------|----------|
| `running` | Часы идут; лазеры анимируются |
| `paused` | Время и лучи заморожены; \(\beta\) можно менять |
| `experiment` | Есть ≥1 активный лазерный импульс |

Переходы реализуй в stores / space-time service явно. Смена \(\beta\) разрешена в любом состоянии.

## 1.8 Что запрещено в UX

- Карточки-«статистика» / badges / chips поверх звёздного поля кабины.
- Purple cyberpunk glow как основной бренд.
- Подмена аберрации простым «zoom к центру» без формулы.
- Пропуск карты наблюдателя «потому что сложно».
- Лазер, скорость которого зависит от \(v\) корабля в системе покоя планет (нарушение постулата).
- Одинаковые часы Земли и корабля при \(\beta>0\).
