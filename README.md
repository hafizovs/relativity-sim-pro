# RelativitySim Pro

Интерактивный симулятор **Специальной теории относительности** (Angular 22+, Signals, Canvas 2D).

Префикс компонентов: `rsp`.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:4200/`.

```bash
npm test    # unit-тесты физики
npm run build
```

## Эффекты СТО

| Эффект | Что видно |
|--------|-----------|
| Лоренц-фактор γ | телеметрия, растёт с β |
| Замедление времени | часы Земли vs корабля (парадокс близнецов) |
| Сокращение длины | корабль на карте наблюдателя: L = L₀/γ |
| Аберрация | звёзды стягиваются к «вперёд» в кабине |
| Доплер | blueshift впереди / redshift сзади; уход из видимого спектра |
| Лазеры | в rest frame \|v\| = c в обе стороны |

## Hotkeys

| Клавиша | Действие |
|---------|----------|
| Space | Play / Pause |
| R | Reset времени и лазеров |
| 0–4 | Пресеты β |
| [ ] | Шаг β |
| F / B | Лазер вперёд / назад |
| S | Screenshot |
| T | Тема |
| G | RU ↔ EN |
| H | Справка |
| Esc | Закрыть overlay |

## Disclaimer

Это **учебная 2D-визуализация** СТО. Не заменяет учебник и не моделирует ОТО, полное релятивистское излучение протяжённых дисков или точный спектральный синтез. Термин «релятивистская масса» \(m\gamma\) — педагогический.
